These are original unmodified simulation scripts uploaded by the author.
They automatically run substantial simulations when sourced. They are NOT
loaded or executed during package installation. Review the top-level
settings (especially B=5000, scenario list, and whether RUN_MAIN is on)
before sourcing them in an R session.

The package's public API has been separated from the simulation DGP,
reference truth, oracle benchmark, and output-writing code.
